# Algorithms

Учебный проект по реализации алгоритмов и структур данных на языке C#. Проект включает алгоритмы сортировки, поиска подстрок, обработки последовательностей, работы с двоичными деревьями и графами.

Для демонстрации работы алгоритмов реализована пошаговая консольная визуализация.

## Содержание

### Mission 1 — Алгоритмы сортировки

- **Bubble Sort** — гибридная сортировка с использованием Comb Sort и Cocktail Sort.
- **Merge Sort** — итеративная сортировка слиянием (Bottom-Up).
- **Quick Sort** — быстрая сортировка со схемой Хоара и выбором опорного элемента методом медианы трёх.

### Mission 2 — Алгоритмы поиска подстрок

- Поиск всех вхождений подстроки с помощью алгоритма Кнута — Морриса — Пратта (KMP).
- Определение минимального циклического сдвига строки вправо.

### Mission 3 — Обработка последовательностей

- Определение минимального количества удалений для получения правильной скобочной последовательности.
- Поиск индекса ближайшего строго меньшего элемента справа с использованием монотонного стека.

### Mission 4 — Двоичные деревья

- Построение двоичного дерева поиска (BST).
- Поиск вершин, имеющих ровно одного ребёнка.
- Проверка сбалансированности двоичного дерева.
- Симметричный и обратный обходы дерева (In-order и Post-order).

### Mission 5 — Алгоритмы на графах

- **Алгоритм Дейкстры** — поиск кратчайших путей от заданной вершины.
- **Алгоритм Флойда — Уоршелла** — поиск кратчайших путей между всеми парами вершин.
- Определение центра взвешенного графа.
